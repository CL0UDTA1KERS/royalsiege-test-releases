ROYALSIEGE / runtime-only test publication

This repository publishes the compiled browser runtime for the owner-approved IIS HTTPS test. It is not the authoring repository. TypeScript, STORY BOARD history, original recordings, full reference images and authoring tools remain private.

The private TypeScript application was freshly type-checked and compiled before publication. HTTP testing required portable SHA-256 because browser SubtleCrypto is unavailable on an HTTP IP origin. The same approved asset digests are still enforced, never bypassed. Approved baked models, animation data and the 30-second soundtrack are reused unchanged. The public environment texture atlas retains only sampled Earth, flag and rock regions.

The workflow recompiles the pinned public JavaScript input, verifies every runtime file, checks deterministic JavaScript output and produces a package with a build receipt. Its source commit identifies this public recipe and input manifest; the separate upstream TypeScript commit identifies the private application build. The workflow does not claim to compile private TypeScript it cannot access.

Release assets and models are public and downloadable. The opt-in Piece movement rehearsal supports chess and all 23 Stratego racks using Xbox-standard, keyboard and touch previews. Racks step one square in any direction to an empty cell, without castling or King/check status. Occupied squares block moves and chess retains its ranks 1-5 rehearsal boundary. Flag, captures/encounters and AI remain inactive; this is not a completed match or mobile/production certification. HTTP redirects to HTTPS, which enables WebGPU where supported. Credits and license notices, including chess.js BSD-2-Clause, are preserved in the runtime package. Creator-supplied art and audio are not independently rights-cleared.
