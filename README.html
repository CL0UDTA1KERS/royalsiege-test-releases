ROYALSIEGE / runtime-only test publication

This repository publishes the compiled browser runtime for the owner-approved IIS port-80 test. It is not the authoring repository. TypeScript, STORY BOARD history, original recordings, full reference images and authoring tools remain private.

The private TypeScript application was freshly type-checked and compiled before publication. Its bundle exactly matched the previously approved scene. Approved baked models, animation data and the 30-second soundtrack are reused unchanged. The public environment texture atlas retains only sampled Earth, flag and rock regions.

The workflow recompiles the pinned public JavaScript input, verifies every runtime file, checks deterministic JavaScript output and produces a package with a build receipt. Its source commit identifies this public recipe and input manifest; the separate upstream TypeScript commit identifies the private application build. The workflow does not claim to compile private TypeScript it cannot access.

Release assets and models are public and downloadable. The current release is a desktop-recommended scene and entrance preview, not completed gameplay or mobile/production certification. HTTP uses WebGL; WebGPU requires a secure context. Credits and license notices are preserved in the runtime package. Creator-supplied art and audio are not independently rights-cleared.
